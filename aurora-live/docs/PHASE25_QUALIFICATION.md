Phase 25 replaces speculative feature scoring with a reproducible, workspace-scoped qualification record.

## Current honest result

Phase 25 intentionally does not generate a single marketing score.

- AURORA is ahead in inspectable claim-level provenance, contradiction records, falsifiers, correction history, and append-only analytical revisions.
- AURORA is behind in documented API operation breadth and sustained public operating history.
- Live-source breadth is not yet comparable because registered sensor capabilities do not prove continuously operating external sources.
- Route/scenario usability, MCP breadth, and resolved forecast calibration remain unverified until direct benchmarks and enough real outcomes exist.
- The superiority flag remains false while any strategic row is behind or not verified.

## Canonical record chain

```text
Sensor
→ immutable Observation
→ correlated Detection
→ atomic Claim
→ supporting or contradicting Evidence
→ operational Incident
→ Alert and Case
→ Forecast and Scenario
→ System Output and Action
→ immutable Audit Event
```

Phase 25 enforces that these records have distinct responsibilities. It does not collapse observations, detections, claims, incidents, and forecasts into one ambiguous event object.

## External gates

The codebase cannot self-certify:

- sustained 99.9% public uptime;
- independent security review;
- third-party detection precision/recall;
- public adoption or battle testing;
- sufficient forecast-resolution history.

Those remain `NOT_VERIFIED`, not successes.

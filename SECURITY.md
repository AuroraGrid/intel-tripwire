# Security Policy

Report vulnerabilities privately to `kazmihasan624@gmail.com`.

Include the affected URL or file, reproduction steps, likely impact, and any relevant logs with sensitive information removed. Do not disclose credentials, private records, personal data, or exploitable details in a public issue.

Relevant reports include exposed secrets, unsafe document rendering, injection, broken access control, privacy leaks, dependency vulnerabilities with a credible exploitation path, and insecure deployment behavior.

Please allow reasonable time for investigation and mitigation before public disclosure. Destructive testing, denial-of-service activity, data exfiltration, and access beyond what is necessary to demonstrate the issue are not authorized.
